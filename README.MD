The mhk2 mod loader is a universal mod loader for *Moorhuhn Kart 2*. It relies on DLL injection, similar to standard modding practices.
Its key feature is support for running multiple mods simultaneously.
Creating mods requires a capable decompiler (such as Ghidra) and C++ programming skills. I have included a template mod and a minimal API for working with the mod loader.
The mods operate on the principle of manipulating the game's memory via a DLL.

I also forgot to mention that the "mhk2 Widescreen fix" mini-mod is included as a bonus; it helps you select a different screen resolution. Please check out the original mod's GitHub page: https://github.com/ermaccer/MHK2.WidescreenFix
